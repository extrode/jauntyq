; Enforces the zero-dependency/NativeAOT-trimming mandate for src/ product
; code (JauntyQ.Runtime and everything it can pull in transitively). LINQ's
; generic iterator/delegate chains defeat trimming and add allocation the
; product doesn't need; List<T>/Array/string already expose native
; equivalents for every LINQ call site found in this codebase to date
; (FindAll/Exists/TrueForAll/Find, Array.Exists/Sort, string.Contains(...,
; StringComparison)). Namespace-level ban catches every Enumerable extension
; method (including comparer-overload gaps like List<T>.Contains(item,
; IEqualityComparer<T>), which silently binds to Enumerable.Contains with no
; compiler warning) in one line, rather than an per-symbol allowlist that a
; future contributor could route around one call at a time.
;
; This file is scoped to src/ only via src/Directory.Build.props; tests/ and
; samples/ are explicitly exempt (see docs/conventions.md / CLAUDE.md's
; testing-philosophy section) and may use LINQ freely.
N:System.Linq;LINQ is banned in src/ product code (NativeAOT/zero-dependency mandate) -- use a plain foreach loop or an existing List<T>/Array/string native method instead. Tests and samples are exempt.
